## Step 1: Jenkins Install Karo

```bash
# Java install karo (agar nahi hai)
sudo apt update
sudo apt install openjdk-21-jdk -y

# Jenkins install karo
curl -fsSL https://pkg.jenkins.io/debian-stable/jenkins.io-2023.key | sudo tee \
  /usr/share/keyrings/jenkins-keyring.asc > /dev/null
echo deb [signed-by=/usr/share/keyrings/jenkins-keyring.asc] \
  https://pkg.jenkins.io/debian-stable binary/ | sudo tee \
  /etc/apt/sources.list.d/jenkins.list > /dev/null

sudo apt update
sudo apt install jenkins -y

# Jenkins start karo
sudo systemctl start jenkins
sudo systemctl enable jenkins
sudo systemctl status jenkins

# Initial password nikalo
sudo cat /var/lib/jenkins/secrets/initialAdminPassword
```

**Browser me kholo**: `http://your-ec2-ip:8080`
- Initial password dalo
- "Install suggested plugins" select karo
- Admin user banao

## Step 2: Required Tools Install Karo

### Maven Install Karo
```bash
sudo apt install maven -y
mvn -version
```

### Node.js Install Karo (Latest v23)
```bash
# Old Node remove karo
sudo apt-get purge nodejs npm -y
sudo apt-get autoremove -y

# Latest Node install karo
curl -fsSL https://deb.nodesource.com/setup_23.x | sudo -E bash -
sudo apt-get install -y nodejs

# Verify karo
node --version    # v23.x.x hona chahiye
npm --version     # v10.x.x hona chahiye

# Jenkins user ke liye accessible banao
sudo chmod +rx /usr/bin/node
sudo chmod +rx /usr/bin/npm
```

### Trivy Install Karo (Security Scanning)
```bash
wget https://github.com/aquasecurity/trivy/releases/download/v0.48.0/trivy_0.48.0_Linux-64bit.deb
sudo dpkg -i trivy_0.48.0_Linux-64bit.deb
trivy --version
```

### Docker Setup Karo
```bash
# Jenkins user ko docker group me add karo
sudo usermod -aG docker jenkins
sudo systemctl restart jenkins

# Verify karo
sudo -u jenkins docker ps
```

## Step 3: SonarQube Setup Karo

```bash
# SonarQube container run karo
docker run -d \
  --name sonarqube \
  -p 9000:9000 \
  -v sonarqube_data:/opt/sonarqube/data \
  -v sonarqube_logs:/opt/sonarqube/logs \
  -v sonarqube_extensions:/opt/sonarqube/extensions \
  sonarqube:lts-community

# Wait karo 2-3 minutes
sleep 120

# Check karo running hai ya nahi
docker logs sonarqube --tail 50
curl http://localhost:9000/api/system/status
```

**Browser me kholo**: `http://your-ec2-ip:9000`
- Login: `admin` / `admin`
- Password change karo
- Token generate karo:
  - My Account → Security → Generate Tokens
  - Name: `jenkins`
  - Type: `Global Analysis Token`
  - Generate karo aur copy karo

## Troubleshooting (Agar Problem Aaye)

### Jenkins Not Accessible
```bash
sudo systemctl status jenkins
sudo systemctl restart jenkins
sudo journalctl -u jenkins -n 100
```

### Maven Not Found
```bash
sudo apt install maven -y
mvn -version
sudo systemctl restart jenkins
```

### Node Not Found
```bash
which node
sudo chmod +rx /usr/bin/node
sudo -u jenkins node --version
```

### Docker Permission Denied
```bash
sudo usermod -aG docker jenkins
sudo systemctl restart jenkins
```

### SonarQube Not Reachable
```bash
docker ps | grep sonarqube
docker logs sonarqube
docker restart sonarqube
```

### Disk Space Full
```bash
df -h
docker system prune -af --volumes
sudo apt-get clean
```
